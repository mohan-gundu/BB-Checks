Setup & Alerts

📧 Email alerts are free via Google Apps Script — no third-party services. Fires instantly on flags, hourly for missed checklists.

1 Install on iPhone (Safari only)

  • Open the app URL in Safari
  • Tap the Share button → Add to Home Screen → Add
  • Appears as a standalone app — no browser bar

2 Install on Android / Chrome

  • Open the app URL in Chrome
  • Tap the three-dot menu → Add to Home Screen
  • Or Chrome may show an install banner automatically

3 Host the app (share with all staff)

  • Create a free account at github.com
  • New repository → upload this HTML file → Settings → Pages → main branch
  • Your URL: yourusername.github.io/repo-name
  • Share this URL — staff add it to their home screen from any device

4 Google Apps Script (logging + alerts)

  • sheets.google.com → new sheet → Extensions → Apps Script
  • Delete all default code, paste the script below
  • Edit MANAGER_EMAIL at the top
  • Deploy → New deployment → Web app → Anyone → Deploy
  • Copy the Web App URL and paste it in Step 5 below
// Consolidated script is stored securely inside Google Apps script environment.

6 Set hourly missed-checklist trigger

  • In Apps Script, click the clock icon (Triggers)
  • + Add Trigger → function: checkMissedChecklists
  • Time-driven → Hour timer → Every hour → Save
  • Authorise when prompted
